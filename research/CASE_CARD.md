# Case card — TVS Credit EPIC 8.0 · Problem (e)

| Field | Value |
|---|---|
| Sponsor | TVS Credit Services Ltd — CRISIL AA+/Stable, NBFC, TVS Motor financing arm |
| Problem statement (e) | "Swarm Intelligence Lending Network" — collective-intelligence platform that continuously learns and identifies hidden relationships across loan applications, device fingerprints, dealer networks, bank accounts, mobile numbers, locations, guarantors, payment behaviours, to **predict emerging fraud ecosystems before fraud occurs** |
| Decision we want a judge to make | Shortlist us to Round 3 (live demo + code walkthrough) |
| Round 2 deliverable | PPT + prototype/screens/wireframe; suggest a **retailer visit**; screened for plagiarism/AI-generated content; original work, relevant research, critical thinking weighted |
| End customer | Tier 3/4, first-time and thin-file borrowers |
| Business outcome | Lower credit costs / write-offs, earlier detection, safer growth in throttled segments |
| Constraints | No access to TVS internal data (we state this openly); synthetic + public data only; 400 teams in Phase 2; ~2-day deadline |
| Evaluation lens | Round 2 = does it understand TVS + is it credible and original? Round 3 = does it work + can they walk us through it? |
| Our differentiator in one line | Everyone can generate a fraud-detection architecture with AI. Nobody can generate a **measured, leak-audited, rerunnable pipeline with honest failures and a measured lead time.** |
| Working definition of success | A judge can: (1) read the numbers on any slide and find the script/source that produced them; (2) run the pipeline in ~30 s locally or in Colab; (3) answer "what would falsify this?" from our own materials. |
| Key unknowns | AR-2025 exact GNPA/credit-cost/segment tables (parse PDF); whether TVS has an internal graph layer (assume partial); real fraud/benign split of credit losses (pilot measures it) |
